## Proposed film treatment

Produce a 15-second, silent 3840 × 2160 master at 30 fps. These are production targets, not claims about the current preview. The generated opening image is 1672 × 941. Avoid mixing “4K” and “8K” delivery specifications in the same production request.

- 0–5 seconds: three-quarter close-up of an adult female engineer at dual monitors. Slow controlled dolly-in; cyan screen bounce and warm practical light. Frame subject right with dark space left for live HTML copy.
- 5–9 seconds: match the monitor plane into a restrained UI assembly. Cards and data connections resolve into a coherent product. Use a smooth depth transition rather than an explosive flash or camera shake.
- 9–12 seconds: a working dashboard resolves. Show the Deploy to Production action, then illustrative activity and a geographic visitor view. Composite accurate interface text in post rather than relying on generated video lettering.
- 12–15 seconds: return through the screen reflection to the opening composition. Match camera position, light level, hands, and screen luminance for the loop. The current preview uses a soft interface dissolve back to the studio image instead.

## Integration

Keep headline and real application CTA as HTML, outside video pixels. Deliver a separate mobile crop centered on the engineer. Use muted, playsInline, loop video with a poster; retain the poster for reduced motion and provide a pause control. Pause playback when offscreen or the document is hidden. Compress separate desktop/mobile renditions and measure loading and mobile GPU performance before setting a bandwidth budget.

The preview's Deploy to Production button changes local demo state only. It performs no deployment. Its chart is illustrative, not live traffic. A world heatmap is part of the proposed finished film, not the current motion study.
